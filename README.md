# HTML-ToDo-App

A personal task board. Every task is one Markdown file with YAML frontmatter, and people and Claude both edit the same files.

| Folder | What it is |
|---|---|
| `app/` | The board (`todo.html`), v0.1.1. Open it in desktop Chrome or Edge and choose a folder of task files. |
| `poc/` | OneDrive proof of concept (spec item R1-10, step 1). See `poc/SETUP.md`. |
| `docs/specs/` | Feedback-round specs. |
| `CLAUDE.md`, `HANDOFF.md` | Context and working rules for Claude Code. |

Live (GitHub Pages): `https://gvd1024.github.io/html-todo-app/app/todo.html` (demo mode only; folder access works only on desktop) and `https://gvd1024.github.io/html-todo-app/poc/`.
